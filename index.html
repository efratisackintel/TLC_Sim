📡 TLC_Sim

WiFi firmware Transmit‑Link‑Control (rate‑scaling) simulation with a data‑driven PER model and interactive teaching docs.

▶ Playground

Set the channel SNR and watch TLC pick MCS / streams / bandwidth / GI. All‑MCS PER chart, PSD‑penalty toggle, throughput axis.

▶ Interactive Architecture

Click blocks B1–B6 for inputs/outputs and flow diagrams. The PER Model Explorer is integrated under B2.

▶ PER Model Explorer

Every measured PER‑vs‑SNR curve, per permutation (frame BW · channel BW · antenna · GI). Log axis + CSV export.
