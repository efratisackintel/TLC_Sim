PPMCS — Per‑Path, Per‑MCS power table

A tiny interactive model to grasp the main idea. Not real firmware values — just the concept.

The idea in one line

The radio has an absolute power limit per channel (from regulatory / SAR / TAS tables). PPMCS adds a small per‑MCS offset on top of it — because higher, denser MCS rates need to be backed off a bit to stay clean. The final TX power for each rate is:

final_power[MCS] = base_limit(band, channel)  +  PPMCS_offset(path, BW, sub‑band, MCS)

These 14 numbers are exactly what one PPMCS cell‑row stores. Drag to see the final power change. Offsets are negative (a back‑off), just like real tables.

In the real firmware each cell is 8 bits per MCS with a fine step (~sub‑dB); here we use dB for clarity.
